# mi-note-export

把小米云服务（i.mi.com）中**你自己账号**的笔记，批量导出为本地 Markdown，含图片、录音等附件。

纯本地运行，只读，不依赖任何第三方服务器。

> 🤖 本项目使用 Claude Opus 5 开发。

## 导出笔记

### 1. 安装依赖

```bash
pip install requests
```

### 2. 获取 Cookie

1. 浏览器打开 <https://i.mi.com/note> 并登录**你自己的账号**
2. 按 F12 打开开发者工具 → 切到 Network 面板 → 刷新页面
3. 找到任意一条 `i.mi.com` 的请求 → 右键 → Copy → Copy as cURL
4. 从中取出 `-b '...'` 引号内的整段内容，保存为项目目录下的 `cookie.txt`

Cookie 有效期约数天，过期后（接口返回 401）重新复制一份覆盖即可。

> `cookie.txt` 等同于你的登录态，切勿分享或提交到版本控制，项目的 `.gitignore` 已默认排除它。

### 3. 试跑

先导出最近 5 条，确认一切正常：

```bash
python mi_note_export.py --limit 5
```

### 4. 全量导出

```bash
python mi_note_export.py -o ./mi-notes
```

中断后重跑会自动跳过已完成的部分，不会重复请求。默认支持增量同步。

### 5. 查看结果

```
mi-notes/
├── <文件夹名>/
│   ├── 笔记标题.md                # 默认用标题命名
│   └── 20240101-重复的标题.md     # 仅当同目录标题重名时才加日期前缀
├── assets/            # 图片、录音等附件
└── .cache/            # 接口原始 JSON，用于断点续传与离线重建
```

每篇带 YAML frontmatter（标题、ID、文件夹、创建与修改时间），正文里的图片已改写为本地相对路径，用 Obsidian、Typora 打开可直接看图。
