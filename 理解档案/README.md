## 阅读原则

1. 原文叙述、本人在本聊天的澄清、旧档案转述的本人回答、AI解释分别标明。
2. 原文能证明当时写过什么，不能自动证明他对别人的动机判断客观正确。
3. 每项稳定模式要寻找跨时间证据和反例；不把一次酒后、失恋或疲惫时的表达固化成人格。
4. 不凭第三人称写作、没哭、梦境或某一句回答作心理诊断；不把否认解释成“恰好证明我说得对”。
5. 不把所有兴趣、幽默、道德选择和职业抱负都归结于丧失或创伤。
6. 日记中的歌词、书摘、虚构、AI回复、录音转写和身体健康笔记逐项区分；其中的医疗说法不当成已验证事实。
7. 亲密记录用于理解关系与感受，档案不复制不必要的性细节、证件、账号或密钥。
8. 当前状态必须注明日期；不将历史自述当作今日状态。
9. 这是一套可重新读取的本地档案，不等于声称每个新聊天都自动拥有完整记忆。
